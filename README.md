# Smart Travel Finance — Image Library

This repository organizes image assets used by Smart Travel Finance.

## Folders
- `california-finance/` — California financial strategy, tax, and simulation imagery
- `loans-credit/` — loans and credit
- `banking-investments/` — banking and investments
- `travel-flights-hotels/` — flights, hotels, and travel
- `news-editorial/` — news and editorial images

Images will be added in their original formats where possible. Direct raw URLs will be shared after each upload is verified.
